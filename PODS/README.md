# 📦 3. PODS (Módulo 3)

Un **Pod** es la unidad mínima de despliegue en Kubernetes: encapsula uno o varios contenedores que comparten dirección IP, espacio de puertos y volúmenes de almacenamiento dentro de un mismo nodo.
